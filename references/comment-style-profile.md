# 个人研究与评论偏好档案

本文件供 Skill 的实际使用者自行填写、修改；可以留空，不影响研究功能。通用研究质量要求见 SKILL.md 和 research-method.md，不在此重复。

## 研究资料的呈现偏好

尚未填写。可按需要记录详略、排版、术语解释等个人要求。

## 最终评论的文风偏好

尚未填写。可按需要记录长度、语气、知识与感受的比例、修辞及应避免的写法。

## 待验证的观察

暂无。仅在使用者委托 AI 维护档案时，用于暂存尚未确认的观察，不作为稳定要求执行。

## 维护规则

- 使用者可直接编辑本文件；AI 仅在使用者明确要求记住、更新或委托持续维护时协助写入。
- 不记录开发者对 Skill 的调试反馈、通用质量要求或其他使用者的偏好。
- 区分研究回答偏好与最终评论文风，记录适用场景；明确表达的偏好可直接采用。
- 获授权从样本观察时，区分使用者原稿、AI 提议与使用者明确采纳的内容。单篇样本只作为待验证观察，跨篇重复或经使用者确认后再确立。
- 尊重手动填写和明确修正，不以模型推测覆盖；有语境差异时保留适用条件。
- 只保存必要的偏好及简短证据摘要，不完整保存评论或不必要的个人敏感信息。
